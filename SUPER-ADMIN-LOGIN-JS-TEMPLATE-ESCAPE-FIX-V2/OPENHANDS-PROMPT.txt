Updated diagnosis:
The previous retry proved that this is NOT a stale-build problem. `npm run build` succeeds but reproduces the malformed browser JavaScript. The Super Admin JavaScript is embedded inside an outer template literal in `server/_core/index.ts`. The current source text `replace(/\/+$/,'')` is cooked by the outer template literal into `replace(//+$/,'')` in the generated HTML. The template source therefore requires one extra backslash: `replace(/\\/+$/,'')`, which emits the intended browser JavaScript `replace(/\/+$/,'')`.
